# 🏦 Bank Management System (C++)

A simple console-based bank management system built using C++ 💻
This project allows managing clients data using file handling, including adding, deleting, updating, searching, and displaying all clients.

---

## ✨ Features

* 📋 Show all clients
* ➕ Add new client
* ❌ Delete client
* ✏️ Update client info
* 🔍 Find client by account number
* 💾 Save data in file (`Clint.txt`)
* 📂 Load data automatically from file

---

## 🛠️ Concepts Used

* File Handling (`fstream`)
* Structs
* Enums
* Vectors
* Functions (modular programming)
* Input validation
* Menu-driven system
* String parsing

---

## 🚀 Purpose

This project was built as a practice on C++ fundamentals, file handling, and real-world problem solving 🧠✨
