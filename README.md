🏦 Banking System in C++ (Full Project Journey)








📌 Overview

A complete banking system project built in C++, developed in 3 progressive stages, starting from basic client management and evolving into a full system with authentication, users, and permissions control.

This project demonstrates:

Real-world system design
File handling persistence
Role-based access control (RBAC)
Modular C++ architecture
