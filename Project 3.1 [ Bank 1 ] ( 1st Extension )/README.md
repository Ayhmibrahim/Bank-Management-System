# 🏦 Bank Management System (C++)

A complete console-based Bank Management System built using C++ 💻
The system allows full management of clients including adding, updating, deleting, searching, deposits, withdrawals, and balance tracking using file handling.

---

## ✨ Features

* 📋 Show all clients
* ➕ Add new client(s)
* ❌ Delete client
* ✏️ Update client info
* 🔍 Find client
* 💰 Deposit money
* 💸 Withdraw money
* 📊 View total balances
* 💾 Data saved in text file (`Clients.txt`)

---

## 🛠️ Concepts Used

* File Handling (`fstream`)
* Structs
* Vectors
* Enums
* Functions (modular design)
* String parsing & splitting
* Input validation
* Menu-driven system
* Transactions logic

---

## 🚀 Project Goal

This project was built to practice real-world C++ applications such as banking systems 🧠
It helps in understanding file-based data storage and structured programming.
