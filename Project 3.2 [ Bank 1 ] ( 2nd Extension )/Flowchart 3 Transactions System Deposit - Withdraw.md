  ↓
────────────────────────────
│ 1 Deposit
│ 2 Withdraw
│ 3 Total Balance
│ 4 Main Menu

  ↓

  ↓

Case 1: Deposit
  ↓
Enter Account Number
  ↓
Find Client
  ↓
Enter Amount
  ↓
Add Amount to Balance
  ↓
Save File
  ↓
Return Menu

--------------------------------

Case 2: Withdraw
  ↓
Enter Account Number
  ↓
Find Client
  ↓
Enter Amount
  ↓
Check Balance >= Amount?
   ├── No → Error Message → Retry
   └── Yes
         ↓
     Subtract Amount
         ↓
     Save File
         ↓
     Return Menu

--------------------------------

Load All Clients
  ↓
Sum All Balances
  ↓
Display Report
  ↓
Return Menu

  ↓
